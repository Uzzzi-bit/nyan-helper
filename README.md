# 🐾 작업냥 nyan-helper

Claude Code 옆에서 일을 도와주는 고양이 조수 패널이에요.
A cat sidekick panel for Claude Code.

```
 /\_/\   ╭──────────────────────╮
( ^ω^ )  │ 다 했어요! 확인해줘요 ✨ │
 > * <   ╰──────────────────────╯
📋 오늘까지 1 · 다음: PR 리뷰
📝 12 · 🧪 3 · ⏱ 1시간 5분  🧠 23%  ⏳ 5%
```

- **📋 할 일**: 마감 드롭다운으로 추가, 오늘까지 / 내일까지 / 나머지로 자동 정렬
- **⚡ 지금**: Claude가 하는 일, 브랜치 경고, 대화 기억 공간(컨텍스트)·사용 한도, 바뀐 파일
- **📊 통계**: 시간대별·최근 7일 차트, 프로젝트 비중, 토큰
- 한국어·영어, 말투 설정(냥체·갸루·담백·직접 입력). 모델 토큰 0

## 설치 / Install

```
/plugin install nyan-helper --marketplace Uzzzi-bit/nyan-helper
```

자세한 기능·설정은 [nyan-helper/README.md](./nyan-helper/README.md)를 보세요.
