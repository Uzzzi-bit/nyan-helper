# 🐾 nyan-helper (작업냥)

Claude Code 옆에서 일을 도와주는 고양이 조수예요. 클로드가 지금 무엇을 하는지, 오늘 얼마나 일했는지를 귀여운 고양이 표정과 함께 보여줘요.
A cat sidekick for Claude Code that shows what Claude is doing right now and what you got done today.

```
(=^•ω•^)ﾉ⌨  열심히 일하는 중이다냥!  shop-api · job.ts 수정 중
📝 3 · 🧪 2 · 🛡️ 0 · ⏱ 12분   [펼치기]
```

## 기능 / Features

- **고양이 + 말풍선**: 패널에선 3줄 고양이 그림 옆 주황 말풍선에 한마디. 표정·발이 상태 따라 바뀜 (쉬는 중 `-ω-` · 작업 중 `oωo` · 확인 대기 `.ω.` · 완료 `^ω^` · 막힘 `;ω;`)
  ```
   /\_/\   ╭──────────────────────╮
  ( ^ω^ )  │ 다 했어요! 확인해줘요 ✨ │
   > * <   ╰──────────────────────╯
  ```
  터미널 띠는 한 줄 얼굴 `(=^▽^=)✨` 그대로
- **지금 하는 일**: 프로젝트 이름과 수정 중인 파일, 실행 중인 명령
- **오늘 통계**: 파일 수정·테스트(성공/실패)·푸시 차단·허락 요청 횟수, 활동 시간, 시간대별 막대 차트, 프로젝트별 비중
- **바뀐 파일**: 이번 대화에서 Claude가 수정한 파일과 횟수 (리뷰용)
- **정리 안 된 저장소**: 수정 중이거나 푸시 안 한 커밋이 있는 git 저장소 (대화 시작·작업 끝날 때 `git status`로 확인, `_`·`.` 폴더 제외)
- **오늘 토큰**: 입력·캐시·출력 토큰 합계 (Claude가 이미 받은 사용량을 더하기만 함)
- **대화 기억 공간(컨텍스트) 사용률**: `🧠 62%` — 80%부터 주황, 90%부터 빨강과 "새 대화 추천" 안내
- **사용 한도**: 5시간·7일 창 사용률과 리셋 시각 (구독 계정에서만 값이 있고, 없으면 숨김)
- **마지막 실패**: 실패한 셸 명령 한 줄. 다음 셸 명령이 성공하면 사라짐
- **방금 작업 요약**: 답변 하나의 소요 시간·수정 파일 수·출력 토큰
- **현재 브랜치**: 작업 중인 프로젝트의 브랜치. 운영 브랜치(`protectedBranches`)면 ⚠️ 경고
- **🐾 Claude 진행**: Claude가 자기 할 일 목록을 쓰면 진행 막대 표시
- **📋 내 할 일 (마감 기준)**: 🔥 오늘까지 · 🌙 내일까지 · 📋 나머지 · ✅ 오늘 한 일, 각 칸은 마감 빠른 순
  - 패널: **마감 드롭다운**(오늘~2주 뒤 · 마감 없음 · 직접 입력)을 고르고 내용 입력 후 Enter. 추가하면 드롭다운은 다시 '오늘'
  - 직접 입력은 `MM/DD`(예: `12/25`)만 받음. 지난 월/일은 내년으로 봄. 틀리면 알림만 띄우고 안 바꿈
  - 각 할 일 옆 드롭다운으로 마감을 바로 바꿈 (직접 입력도 가능)
  - 명령: `/nyan todo PR 리뷰 / 금` — 마감 글 형식: `오늘` `내일` `모레` · `11/28` `11-28` `2026-11-28` · `월`~`일`(`금요일`도 됨) · `+3`. `/` 앞뒤는 띄어 쓰기. 못 읽으면 추가 안 함
  - 마감을 안 정하면 '나머지' 맨 끝
  - 마감 지난 일은 '오늘까지' 맨 위에 빨간 `⚠️ 2일 지남`
  - 체크박스가 버튼: `☐` 누르면 완료, `☑` 누르면 완료 취소 · `✕` 삭제
  - 오늘 한 일 아래에 자동 기록(작업한 프로젝트·시간)이 같이 나옴
  - 대화를 새로 열어도 남음. 끝낸 지 7일 지난 항목은 자동 정리 (한 항목 최대 80자)
- **📅 최근 7일**: 요일별 작업 시간 막대와 `어제보다 +40분` 비교 (설치한 날부터 쌓임)
- **모델 토큰 0**: 모든 화면은 로컬에서 그려지고 모델로 아무것도 보내지 않아요

## 화면 / Where it shows

| 화면 | 모습 |
|---|---|
| VS Code | 대화창 안 접이식 패널 (자동으로 열림). 접힘 = 상태·할 일·통계 3줄(+경고). 펼침 = 머리줄(고양이·🧠·⏳·`접기`) + 탭 3개: **📋 할 일**(목록·추가·오늘 한 일) · **⚡ 지금**(작업 중인 것·컨텍스트·한도·바뀐 파일·저장소) · **📊 통계**(차트·최근 7일·프로젝트·토큰). 마지막 탭 기억. `/nyan` 명령으로 펼침 |
| 터미널·데스크톱 앱 | 입력창 위 한 줄 띠 + `/nyan` 패널 |

## 설정 / Settings

`/config`의 nyan-helper 항목에서 바꿔요.

| 항목 | 값 | 기본 |
|---|---|---|
| `language` | `auto` · `ko` · `en` | `auto` = Claude의 `language` 설정을 따르고, 없으면 한국어 |
| `tone` | `nyan`(냥체) · `gyaru` · `plain`(담백) · `custom` | `nyan` |
| `protectedBranches` | 쉼표로 구분한 브랜치 이름. 여기서 작업 중이면 경고 | `main,master` |
| `customLines` | `custom`일 때 `작업중\|대기\|완료\|막힘\|허락대기` | (빈칸은 냥체) |

## 프로젝트 이름 판별 / Project detection

- 연 폴더가 git 저장소면 → 그 폴더 이름
- 여러 저장소를 담은 작업 폴더면 → 경로에서 바로 아래 폴더 이름 (`_`로 시작하는 보관 폴더는 한 단계 더 안쪽, `.` 폴더는 무시)

## 설치 / Install

Claude Code 안에서 (2.1.275 이상):
```
/plugin install nyan-helper --marketplace Uzzzi-bit/nyan-helper
```
또는 터미널에서:
```bash
claude plugin marketplace add Uzzzi-bit/nyan-helper
claude plugin install nyan-helper@my-plugins
```
설치 후 `/reload-plugins` 또는 재시작. VS Code에서 패널이 안 보이면 `/nyan`.
대화창이 넓으면 오른쪽 옆에, 좁으면 입력창 위에 붙어요 (위치는 VS Code가 폭으로 정함).
